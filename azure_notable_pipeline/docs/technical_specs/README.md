# Azure technical specifications

[`AZURE_AWS_PARITY_TECHNICAL_SPEC.md`](AZURE_AWS_PARITY_TECHNICAL_SPEC.md) is
the normative shipped Azure v1 behavior and operations contract. Live staging
evidence remains deployment-specific and is captured with the readiness package.

The Government deployment profile, security model, and recovery boundaries are
documented in the [customer configuration guide](../operations/deployment/AZURE_GOVERNMENT_CUSTOMER_CONFIGURATION.md)
and [Azure Government architecture](../architecture/AZURE_GOVERNMENT_ARCHITECTURE.md).
